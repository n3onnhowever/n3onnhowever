# Third-party profile components

The visual components in this profile are generated by established open-source projects. Their renderer output is stored locally for availability and is not redrawn or reimplemented in this repository.

- Project: <https://github.com/kyechan99/capsule-render>
- License: [MIT](https://github.com/kyechan99/capsule-render/blob/master/LICENSE)
- Files: `assets/header.svg`, `assets/footer.svg`
- Use: unmodified output from the official renderer API
